# Portal Layanan Akademik (HTML + CSS)
Versi statis: tanpa PHP, database, maupun JavaScript. Buka `index.html` di browser.
- index.html: beranda, layanan, formulir (dikirim via mailto, validasi HTML)
- status.html: petunjuk cek status + contoh hasil
- admin/login.html, admin/index.html: tampilan contoh panel petugas (data tiruan)
